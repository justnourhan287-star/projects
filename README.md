

# 🤖 Line Follower & Obstacle Avoiding Robot

An autonomous robotic vehicle designed to navigate along a black line path and automatically detect and avoid obstacles in its path.

---

## 🛠️ Hardware Components

* Microcontroller: Arduino UNO
* Motor Driver: L298N DC Motor Driver Module
* Sensors:
  * 2x Infrared (IR) Line Tracking Sensors
  * 1x Ultrasonic Sensor (HC-SR04)
* Actuators: 1x SG90 Servo Motor & DC Motors
* Power Supply: External Battery Source

---

## 💻 Tech Stack & Tools

* Programming Language: C++ / Embedded C
* IDE: Arduino IDE
* Simulation: Tinkercad / Wokwi

---

## 📌 Features

* Line Tracking: Follows black tracks accurately using dual IR sensors.
* Obstacle Avoidance: Measures distance using the Ultrasonic sensor and scans surrounding space via Servo motor.
* Autonomous Decision Making: Changes direction dynamically when an object is detected.

---

## 🚀 How to Run

1. Open the LF_and_OA_Robot.ino file in Arduino IDE.
2. Connect your Arduino UNO board via USB.
3. Select the correct Board and Port from Tools menu.
4. Upload the code to the board and test the hardware setup.
